# AI文章自动生成与发布系统

**纯 Python 实现** - 使用 FastAPI + PySide6 构建，完全符合"Python 为唯一开发语言"的规范要求。

## 技术栈

| 组件     | 技术         | 说明                                |
| -------- | ------------ | ----------------------------------- |
| 后端 API | FastAPI      | RESTful API 服务                    |
| 桌面 GUI | PySide6      | 纯 Python 桌面界面（Qt for Python） |
| 数据库   | SQLite       | 轻量级数据存储                      |
| 依赖管理 | uv           | Python 依赖版本锁定                 |
| AI 服务  | DeepSeek API | 文章内容生成                        |
| CMS 对接 | WordPress    | 文章发布平台                        |

## 快速开始

### 方式一：本地运行（推荐）

```bash
cd backend

# 安装 uv（如果未安装）
pip install uv

# 安装依赖
uv sync

# 1. 启动后端 API（终端 1）
uv run python main.py

# 2. 启动桌面 GUI（终端 2）
uv run python -m gui.main_window
```

### 方式二：Docker + 本地 GUI

```bash
# 1. 使用 Docker 启动后端服务
docker-compose up -d

# 2. 本地启动桌面 GUI
cd backend
uv sync
uv run python -m gui.main_window
```

## 核心特性

### 流量控制（细水长流发布）

系统支持"批量生成，分批发布"的 SEO 优化策略：

- **生成数量**：一次生成任务创建的文章数量（如 50 篇）
- **发布数量**：每次定时任务发布的文章数量（如 1 篇）
- **发布频率**：定时任务执行间隔（如每 1 天）

示例配置：生成 50 篇 → 每天发布 1 篇 → 持续 50 天

### SEO 优化

- 标题生成：30-60 字符，自然包含关键词
- 内容生成：800-1500 字，关键词密度 2%-5%
- 结构化输出：H2/H3 标题组织

### 智能重试

DeepSeek API 调用支持指数退避重试机制，自动处理 429、500 等临时错误。

## 规范遵循

- ✅ **开发语言**：Python 为唯一开发语言（PySide6 桌面 GUI，无 Web 技术）
- ✅ **依赖管理**：使用 uv 工具，支持 uv.lock 版本锁定
- ✅ **SEO 优化**：提示词包含关键词布局、语义连贯性设计
- ✅ **错误处理**：完善的异常捕获和用户提示
- ✅ **日志系统**：详细的操作日志记录

## 为什么使用桌面 GUI？

根据规范要求"Python 为唯一开发语言"，我们选择了 PySide6（Qt for Python）作为界面框架：

- **纯 Python**：开发和运行都是 Python，不涉及任何 Web 技术（HTML/CSS/JavaScript）
- **原生体验**：桌面应用，响应快速，无需浏览器
- **跨平台**：支持 Windows、macOS、Linux
